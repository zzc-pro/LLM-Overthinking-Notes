# Papers about efficient CoT from NeurIPS 2025, ICML 2025, ICLR 2026 (Regularly updated)

Though comprehensive surveys on efficient CoT already exist, this repo still surveys recent papers from the top-3 ML conferences (NeurIPS, ICML, ICLR) over the past two years, which are more up-to-date.

## Table of contents

| Title | Code | Conference | Brief Intro |
| :---- | :--: | :--------: | :---------- |
| [Do NOT Think That Much for 2+3=? On the Overthinking of Long Reasoning Models](https://arxiv.org/pdf/2412.21187) | [Code](https://github.com/galaxyChen/overthinking) | ICML 2025 | First comprehensive study of overthinking in o1-like LRMs; proposes outcome/process efficiency metrics and a self-training paradigm that streamlines reasoning without sacrificing accuracy. |
| [PENCIL: Long Thoughts with Short Memory](https://arxiv.org/abs/2503.14337) | [Code](https://github.com/chr26195/PENCIL) | ICML 2025 | Introduces a recursive reduction mechanism that erases no-longer-needed intermediate thoughts during generation, enabling long-CoT reasoning under bounded context and compute. |
| [Rethinking Chain-of-Thought from the Perspective of Self-Training](https://arxiv.org/pdf/2412.10827) | [Code](https://github.com/zongqianwu/ST-COT) | ICML 2025 | Frames CoT as self-training with task-specific prompts and adaptive iteration, mitigating over-reasoning and inter-iteration redundancy while improving efficiency. |
| [MME-CoT: Benchmarking Chain-of-Thought in Large Multimodal Models for Reasoning Quality, Robustness, and Efficiency](https://arxiv.org/abs/2502.09621) | [Code](https://github.com/MME-Benchmarks/MME-CoT) | ICML 2025 | A multimodal CoT benchmark with fine-grained quality/robustness/efficiency metrics, revealing reflection-driven gains, overthinking on perception tasks, and inefficiency in LMM CoT. |
| [VeriThinker: Learning to Verify Makes Reasoning Model Efficien](https://arxiv.org/abs/2505.17941) | [Code](https://github.com/czg1225/VeriThinker) | NeurIPS 2025 | Fine-tunes LRMs only on an auxiliary solution-verification task, which makes them discerning about self-reflection and suppresses overthinking, compressing CoT while slightly improving accuracy. |
| [A*-Thought: Efficient Reasoning via Bidirectional Compression for Low-Resource Settings](https://arxiv.org/abs/2505.24550) | [Code](https://github.com/AI9Stars/AStar-Thought) | NeurIPS 2025 | Casts reasoning as an A*-guided tree search with a bidirectional importance estimator to select high-density low-cost paths; the compressed traces are then used for SFT to teach the model concise reasoning. |
| [SemCoT: Accelerating Chain-of-Thought Reasoning through Semantically-Aligned Implicit Tokens](https://arxiv.org/abs/2510.24940) | [Code](https://github.com/YinhanHe123/SemCoT/) | NeurIPS 2025 | Uses a contrastively trained sentence transformer to enforce semantic alignment between implicit and explicit reasoning, plus a distilled lightweight generator to speed up implicit-token generation. |
| [Causal Sufficiency and Necessity Improves Chain-of-Thought Reasoning](https://arxiv.org/pdf/2506.09853) | [Code](https://github.com/yxn9191/causalmath) | NeurIPS 2025 | A causal framework using Probability of Sufficiency and Necessity to quantify each step's influence, enabling automated addition of missing steps and pruning of redundant ones; the optimized traces can be used for in-context learning or SFT. |
| [How Far Are We from Optimal Reasoning Efficiency?](https://arxiv.org/pdf/2506.07104) | [Code](https://github.com/samjia2000/Optimal-Reasoning-Efficiency) | NuerIPS 2025 | Defines empirical efficiency frontiers and a Reasoning Efficiency Gap (REG) metric, and proposes REO-RL over a sparse set of token budgets to close the gap. |
| [Think Silently, Think Fast: Dynamic Latent Compression of LLM Reasoning Chains](https://arxiv.org/pdf/2505.16552) | [Code](https://github.com/xiaomi-research/colar) | NeurIPS 2025 | Compresses reasoning in latent space via next-compressed-embedding prediction in SFT plus RL exploration, shortening the reasoning chain while preserving accuracy and allowing inference-time compression control. |
| [System-1.5 Reasoning: Traversal in Language and Latent Spaces with Dynamic Shortcuts](https://arxiv.org/abs/2505.18962) | / | NeurIPS 2025 | Inserts dynamic depth (early-exit) and step (hidden-state reuse) shortcuts in latent space via two-stage self-distillation, distinguishing critical from trivial steps to accelerate CoT by 20x. |
| [Thinkless: LLM Learns When to Think](https://arxiv.org/pdf/2505.13379) | [Code](https://github.com/VainF/Thinkless) | NeurIPS 2025 | Trains LLMs with Decoupled GRPO to adaptively choose between `<short>` and `<think>` modes based on task complexity, cutting long-chain thinking usage by 50–90%. |
| [Learning When to Think: Shaping Adaptive Reasoning in R1-Style Models via Multi-Stage RL](https://arxiv.org/pdf/2505.10832) | [Code](https://github.com/ScienceOne-AI/AutoThink) | NeurIPS 2025 | Multi-stage RL framework leveraging an ellipsis-triggered thinking/no-thinking mode in R1-style models, invoking explicit reasoning only when necessary to trade off accuracy and tokens. |
| [Let LRMs Break Free from Overthinking via Self-Braking Tuning](https://arxiv.org/abs/2505.14604) | [Code](https://github.com/ZJU-REAL/Self-Braking-Tuning) | NeurIPS 2025 | Lets the model self-regulate reasoning length via answer-based overthinking identification metrics and a braking prompt, removing reliance on external intervention while preserving accuracy. |
| [Mitigating Overthinking in Large Reasoning Models via Manifold Steering](https://arxiv.org/abs/2505.22411) | / | NeurIPS 2025 | **Training-free.** Projects activation-steering directions onto a low-dimensional manifold tied to overthinking, reducing output tokens by up to 71% with maintained or improved accuracy. |
| [Think or Not? Exploring Thinking Efficiency in Large Reasoning Models via an Information-Theoretic Lens](https://arxiv.org/pdf/2505.18237) | [Code](https://github.com/chicosirius/think-or-not) | NeurIPS 2025 | **Training-free.** Proposes InfoBias/InfoGain metrics that expose length–efficiency tradeoffs, and an entropy-based adaptive halting strategy that cuts tokens ~50% with accuracy gains. |
| [TokenSqueeze: Performance-Preserving Compression for Reasoning LLMs](https://arxiv.org/abs/2511.13223) | [Code](https://github.com/zhangyx1122/TokenSqueeze) | NeurIPS 2025 | A Long2Short method using only self-generated data, with adaptive depth matching and distribution-aligned linguistic refinement, halving tokens while preserving accuracy. |
| [Making Slow Thinking Faster: Compressing LLM Chain-of-Thought via Step Entropy](https://arxiv.org/abs/2508.03346) | [Code](https://github.com/staymylove/COT_Compresstion_via_Step_entropy) | ICLR 2026 | Uses step entropy to identify redundant CoT steps and an SFT+GRPO two-stage training with `[SKIP]` tokens so LLMs autonomously generate compressed CoTs at inference. |
| [Not All Thoughts are Generated Equal: Efficient LLM Reasoning via Multi-Turn Reinforcement Learning](https://arxiv.org/pdf/2505.11827) | [Code](https://github.com/usail-hkust/LongShort) | ICLR 2026 | Pairs a long-thought LLM (important steps) with a short-thought LLM (remaining steps) via synergizing-oriented multi-turn RL, reducing tokens by 80%+ without performance loss. |
| [Pruning Long Chain-of-Thought in Large Reasoning Models via Small-Scale Preference Optimization](https://arxiv.org/pdf/2508.10164) | [Code](https://github.com/SleepyWithoutCoffee/Small_Scale) | ICLR 2026 | Proposes Length Controlled Preference Optimization (LCPO) under a unified Bradley-Terry framework to learn length preference with limited data, cutting output length 50%+ while preserving reasoning. |
| [When More is Less: Understanding Chain-of-Thought Length in LLMs](https://arxiv.org/pdf/2502.07266) | / | ICLR 2026 | Shows accuracy follows an inverted-U curve in CoT length and derives scaling laws (optimal length grows with task difficulty, shrinks with model capability), guiding length-aware CoT calibration. |
| [Segment-Level Attribution for Selective Learning of Long Reasoning Traces](https://arxiv.org/pdf/2602.00425) | [Code](https://github.com/SiyuanWangw/SegmentSelectiveSFT) | ICLR 2026 | Uses integrated-gradient attribution to identify reflective segments (high attribution strength, moderate direction consistency) and applies selective SFT masking, improving learning from long traces. |
| [Thinking in Latents: Adaptive Anchor Refinement for Implicit Reasoning in LLMs](https://arxiv.org/pdf/2603.15051) | / | ICLR 2026 Workshop | Refines latent anchor vectors with an adaptive halting mechanism based on anchor stability, reducing latent steps 48–60% and generated tokens 92–93% with accuracy gains. |
